# Updates

## 0.3.0 - Blade Runner fully playable (user confirmed)

- `PinEvent_V2_Settings.txt` now holds 193 exact typelib enum Consts (keys, music effects, bulb, light sequencer, DMD/segment effects), generated by `scripts/fp_enums.py`. Wine's VBScript does not import host typelib enums (host methods like `GetKeyCode` do work). Hand-typed values were wrong (`SeqAllOff=1000`, `BulbBlink=3`, `SeqUpOn=1`). Generic-name enums (Metal/Wood/Plastic/Yes/...) are left out because tables declare them.
- Video: `HighQualityTextures=1`, `NonPowerOf2Textures=0` works; the GLU crash (`gluBuild2DMipmaps`) needed HQ+NPOT together. Keep NPOT off.
- Debug instrumentation removed from the settings script.

## 0.2.16 - Coin/start keys: fpKeyCode enum indices

- `GetKeyCode()` works under Wine; only the `fpKeyCode` enum names are missing. Runtime probe: `GetKeyCode(0..16)` = 42,54,2,6,28,44,57,53,30,39,41,7,8,30,40,20,31 (DirectInput scan codes).
- Key Consts are now enum indices 0..16 (`InsertCoinKey=3` → key `5`). The old VK values (`53`) made `GetKeyCode` return 0, so coin/start never matched.
- Include proven loaded at runtime (cwd `C:\Games\Future Pinball\Tables`). `scripts/agent_run_fp.py` launches FPLoader, logs, captures FP windows; `scripts/fpt_script.py` dumps a table's VBScript (zLZO).
- Known: `newton.dll+0x43de9` write fault after ~1-2 min of unattended run (separate issue).

## 0.2.8 - Console is VNC on Ubuntu 26.04

- QEMU 10.2 reports spice graphics as unsupported. The spice module package pulls glib 2.83 and its OpenGL module crashes this system's glib 2.82, so those packages were removed.

## 0.2.7 - Windows start no longer hangs

- The libvirt start hook called `virsh` while libvirt was still waiting for the hook, so `win11` stayed paused and a new start never returned. The hook now returns immediately and adds the QXL console from a separate process.

## 0.2.6 - Quadro at PCI 01:00.0, ACPI OEM is Lenovo

- Moved the P1000 and its HDMI audio to guest PCI `01:00.0`. The old device node (guest bus 7) is gone. The new node is `...\4&336A283&0&0010`.
- QEMU ACPI tables and the battery SSDT now use OEM id LENOVO (`-machine x-oem-id=LENOVO,x-oem-table-id=THINKP52`). The driver was still starting against tables labeled BOCHS.
- Code 43 remains on driver 32.0.15.7322: `CM_PROB_FAILED_POST_START`, problem status 0. The new node's first start was `0xC0000493` (`STATUS_DEVICE_POWER_FAILURE`).
- Laptop console is a non-VGA QXL hot-added on `pci.6` after start. Video model stays `none` so the Quadro is the only VGA.

## 0.2.5 - Debug logging removed

## 0.2.4 - Windows clicks work

## 0.2.3 - Ubuntu pointer stays visible; Lan Mouse removed

- spice-gtk was setting a cursor named "none" on the console window, so the pointer vanished over Windows and on the Ubuntu desktop. `scripts/show-cursor.c` forces the normal desktop cursor. The viewer is running with that preload.
- Lan Mouse is closed in Windows. `lan-mouse.exe` was not running, and both `AppData\Local\lan-mouse` and the Startup `lan-mouse.bat` are gone.

## 0.2.2 - Visible pointer on the Windows window

- SPICE was in client mouse mode with a cursor channel, and the viewer used the default cursor mode, so the guest cursor was hidden and the Ubuntu pointer did not replace it.
- Reopen the console with `remote-viewer --cursor=local` so the same pointer used on the Ubuntu desktop stays visible over Windows.
